# Fusion Pixel Font

Upstream: https://github.com/TakWolf/fusion-pixel-font

Version: 2026.11.10. Unmodified proportional OpenType WOFF2 files, zh_hans variants, at 8px, 10px and 12px. These variants include shared glyphs for other supported writing systems, with Simplified Chinese glyph forms taking precedence. The bundled OFL.txt includes the upstream copyright and SIL Open Font License.

Sources: release assets named `fusion-pixel-font-{8,10,12}px-proportional-otf.woff2-v2026.11.10.zip`. No Nothing/NDot font files are included.

The dot matrix scene uses normal weight, native pixel sizes and integer multiples, with one grid column of letter spacing. Unsupported characters retain the configured font fallback. Other player styles do not use these font faces.
