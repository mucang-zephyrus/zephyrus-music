# Zephyrus Music v1.4.2

### 名称与仓库

- 应用更名为 Zephyrus Music，更新应用名称、通知、分享水印、官网和文档中的名称。
- 原 GitHub 账号无法登录，源码迁移至 [mucang-zephyrus/zephyrus-music](https://github.com/mucang-zephyrus/zephyrus-music)。应用内源码、协议和桌面更新入口同步调整。

### 播放器与歌词

- 新增词云和点阵播放器；词云替换狂热，当前共七种样式。词云随演唱展开整曲画布，点阵支持圆点、方格和鼓点效果。
- 电脑端进度条悬停预览支持逐字进度、对唱、背景和声、翻译与发音；间奏显示静态三点。预览居中显示，宽度随歌词变化，显示内容独立于全局歌词设置。
- 智能整理双语歌词，支持按歌曲和来源关闭，增加合并预览与反馈入口。
- 增加首尾制作信息隐藏和自定义关键词。
- 改善默认播放界面布局、封面与歌词切换、歌词定位和队列入场效果，修复部分设置操作触发歌词页面手势的问题。

### 音乐与播放

- 搜索页支持导入网易云、QQ 音乐和酷狗分享链接，识别歌曲后播放。
- 网易云新增增强请求方式，可在播放设置中切换。
- iOS Web 新增防打断模式，开启后关闭媒体通知与锁屏控制。
- 改善慢网下的起播等待、切歌与智能过渡。
- 歌手页增加专辑封面往返过渡，专辑与歌单封面可翻转查看简介。
