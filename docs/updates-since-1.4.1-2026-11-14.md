## 1. 词云播放器

- 用词云替换狂热入口，接入桌面、移动及浮动播放入口。
- 旧 frenzy 选择迁移为 wordCloud，保留兼容配置；旧故障、红字、巨字等专属参数不再作为新样式设置。
- 整曲歌词形成固定画布，播放时逐渐显现，已唱内容保留；普通 LRC 整句显现，可靠逐字数据按原始时间显现。
- 最终采用统一字号的排版，不再使用初始方案中的大小词／词性强调机制；保留主题色调色变化及横竖句排列。
- 排版与镜头参考 Folia 浮名：按阅读顺序组织词句，保留重复句，进行碰撞与边界处理。
- 全景按物理屏幕边界适配；控件叠在词云上方，显隐不应重新排布整曲画布。
- 聚焦镜头跟随当前句／词，支持缩放及旋转；移动可中途改变目标。
- 间奏停留在上一句末端并轻微漂浮；最后一段演唱到中段开始退全景，替代初版“间奏全景＋模糊＋三点”。
- 无时间歌词静态展示；辅助翻译、罗马音、和声及重叠演唱沿用统一显示数据。
- 支持六种背景：几何网格、AMLL 网格渐变、封面模糊、高速流体、太阳耀斑、鼓点涟漪。
- 涟漪背景移植自用户提供的 HTML 效果，增加自动变色及鼓点触发。
- 提供聚焦、间奏估算、字号倍率、句间距、竖句比例和镜头速度等配置，沿用原始／自定义及持久化机制。
- 页面隐藏、场景被覆盖及暂停落定时减少绘制；动态背景保留健康降级。
- 保留图片分享；视频分享界面和导出服务明确阻止词云导出。

## 2. 点阵播放器

- 新增白底浅灰点阵／方格播放器，桌面、移动及浮动入口共享场景。
- 歌词直接点亮背景网格中的单元组成字形，不额外覆盖一层文字或漂移的点。
- 普通 LRC 整句显示，不再估计每字时长；可靠逐字歌词按真实分词起点亮起。
- 分词砸落通过整数网格行上的单元切换实现，可关闭。
- 引入 Fusion Pixel Font，使用原生 8／10／12 像素规格或整数倍，保留字距，降低中文粘连；缺字沿用字体回退。
- 长句自动换行；密集歌词在加载整曲时统一调整网格密度，播放过程中不反复改变网格。
- 前奏及间奏低响度时按可靠 BPM 点亮随机单元，鼓点驱动全网格渐变；高响度时用 45° 斜线扫屏。
- 高潮提供同心波纹、棋盘呼吸、放射推进，可自动轮换或固定；没有可靠音频分析时不伪造鼓点。
- 支持圆点／方格、高潮效果、鼓点响应、分词砸落、间距、半径、字形高度和效果强度设置。
- 保留翻译、罗马音及重叠演唱兼容；暂停、遮挡、后台及减少动态效果模式下收敛动画。
- 保留图片分享，明确阻止视频导出。

## 3. 智能翻译合并与歌词处理

- 将智能整理集中到 MusicHook 的显示入口，网络、缓存、手动匹配及本地歌词使用同一投影流程。
- 原始歌词保留；同步生成显示文本、时间索引和 mergeInfo，避免只改正文而遗漏逐字内容或时间数组。
- 修复句尾括号拆译及 50ms 内同时间双行合并的接线；支持反序双行及可靠逐字文本映射。
- 用整体结构门控替代春晓歌词合并的强制歌曲 ID 白名单；歌名展示使用的白名单不因此移除。
- 跨时间允许 1–3 行原文与 1–3 行译文组成一组；至少六组、双语覆盖均达 85%、方向优势至少 10 个百分点等条件满足才启用。
- 制作信息、空白、和声、官方翻译、不可靠混合文字及过长间隔构成边界；双方都有独立逐字演唱等冲突情况保留原样。
- 针对《长大就好了》专辑补充修复：同行中英后缀、无时间文本双语分组、制作角色识别、罗马音保留及供应商重复辅助文本处理。
- 多行原文合组保留原词时间与次序，点击从首条原文开始；普通 LRC 不制造逐字时间。
- 官方翻译、罗马音先对齐；TTML 的结构化翻译、背景和声及对唱不参与语言猜测。
- 在实际应用规则的滚动歌词末尾加入提示与反馈入口，不把提示加入歌词数组或时间索引。
- 反馈面板固定打开时的歌曲和来源，允许预览算法版本、规则及少量前后片段，复用现有反馈接口。
- 可按“歌曲平台／ID＋实际歌词来源”在本设备关闭智能合并，并从歌词来源设置恢复；官方翻译保留。
- 旧自动缓存按 schema 2 刷新；旧手动选择保留，无法恢复原文的快照不继续叠加处理。
- 异步投影通过请求序号及歌曲／歌词身份校验防止旧结果覆盖新歌。
- 增加隐藏首尾制作信息及自定义关键词；匹配完整角色，保留时间线，不把普通正文中的任意冒号当署名。
- 将制作信息显示处理接入 TTML、进度预览、桌面歌词及各样式显示源，减少不同入口内容不一致。

## 4. 播放界面、滚动歌词与队列

- 默认样式在封面页已显示歌词时，复用同一 AMLL 容器扩展进入歌词页，减少重复构造及零尺寸布局问题。
- 调整控件显示期间的歌词上下边界，避开顶部信息栏，收紧进度条上方空白。
- 修正歌词页控件自动隐藏的计时衔接，减少刚滑入就隐藏的问题。
- 处理容器尺寸变化时 AMLL 当前行定位与动画叠加造成的快速滑动／过冲。
- 新增可测量挂载机制：等歌词宿主真实可见且宽高有效后再创建 AMLL。
- 修复词云、点阵往返封面页／滚动歌词页后歌词残缺、反复进入直至空白的问题。
- 点击歌词页顶部信息栏中的歌曲封面可返回封面页。
- 播放界面队列增加类似 AMLL 的逐行入场，虚拟列表先定位当前歌曲，再按可见顺序播放动画。
- 修复默认样式布局等设置子页点击穿透到歌词，改善设置面板高度及事件隔离。
- 优化默认播放页竖屏封面、信息、歌词的空间分配与可用高度适配。

## 7. 播放可靠性、iOS 与网易云请求

- 在取新歌详情／播放地址之前使旧加载失效，防止旧音源迟到回调重新激活。
- stall／contextlost 软恢复增加当前歌曲身份校验，避免“新歌信息、旧歌音频”。
- 失败或已被后续切歌取代的请求，不应继续改变当前播放状态或触发旧歌恢复。
- 起播不再等待歌词及封面取色，辅助数据后台补齐，并保留手动选择歌词与切歌请求隔离。
- 避免歌曲详情链重复等待封面取色；取色增加 2.5 秒等待上限及画布异常兜底。
- 音频分析 CORS 探测增加 1.5 秒上限，超时回普通播放，不把超时长期缓存成不支持；响应体取消不再阻塞探测结束。
- iOS Web／PWA 自动识别支持情况并提示防打断模式；经确认后使用 ambient 会话及直通播放分支，保存本设备选择。
- 防打断开启时停用媒体通知／锁屏控制，并提示 iPhone 静音会使音频无声；可关闭恢复。该机制不承诺抵抗所有系统中断。
- 媒体通知使用歌词作标题时，歌手栏保留“歌手／歌名”，降低原歌名丢失的问题。
- 改进节拍对齐和混音曲线：限制等待乐句边界的时间，分频过渡采用低频保持后换手及中高频等功率变化，自动化可取消。
- 设置增加网易云 Alger／增强请求方式，选择持久保存；统一请求层覆盖播放地址、详情及播放列表等共用入口。
- 增强取链附带 randomCNIP；在途重试保持原请求方式，避免切设置时同一请求中途更换后端。
- HTTP 200 包装内的 -460 也按错误进入既有处理链；按用户要求移除额外的单次及连续风控提示机制。
- 新增首页网易云服务公告及跳转播放设置入口，说明 Web 可切请求方式、Android 需等待新版。
- API 模式切换不等于图片／媒体 CDN 改线路；境外或代理出口的实际传输瓶颈不能据此宣称消除。
