# 点阵播放器

在「播放设置 → 控制 → 样式」选择「点阵」。桌面、移动端和浮动入口共用场景。

## 视觉和歌词

- 默认白底、浅灰圆点。可切换方格网；歌词和背景始终共用一张固定网格。
- 字形由网格单元的颜色变化组成，没有另画一层文字或位移的点。
- 普通 LRC 整句显示，不估计每字演唱时长。可靠逐字数据按语言分词，在词语真实起始时间点亮。
- 分词砸落通过切换整数行上的网格单元完成，可在自定义设置中关闭。
- 复用现有歌词来源、智能翻译合并、时间校准、翻译及罗马音设置；不会修改原始歌词。
- 歌词使用内置 Fusion Pixel Font（2026.11.10，OFL），优先简体中文字形，采用 8／10／12 像素原生规格或整数倍，关闭合成粗体并保留一格字距。其他样式不受影响，未覆盖字符沿用自定义字体回退。
- 长句自动换行并选择较小的原生规格。密集歌词会在整首歌加载时统一增加网格密度，不再将字形任意压缩；播放推进不改变网格。和声使用较小的原生规格，同时保留至多两条主唱和一条和声。

## 音乐响应

- 前奏、间奏低响度时，按已有 BPM 检测结果随机点亮单元；鼓点带动全网格渐变。
- 高响度时以连接相邻网格点的 45° 斜线扫过屏幕。
- 高潮提供同心波纹、棋盘呼吸、放射推进，可自动轮换或固定一种。
- 复用现有音频分析；没有可靠分析数据时不伪造 BPM 或鼓点。
- 普通 LRC 只有明确空白时间标记才判断句后间奏，不把解析器补齐的 duration 当作演唱句尾。
- 暂停后完成当前渐变并停止绘制；场景被覆盖或页面隐藏时停止绘制。减少动态效果模式关闭背景运动和砸落。

## 设置和兼容

沿用「原始设置／自定义设置」及现有本地持久化入口。可调圆点／方格、高潮动画、鼓点响应、分词砸落、间距、圆点半径、字形高度和效果强度，五种语言均提供文案。

图片分享沿用现有入口。视频导出界面和导出服务明确拒绝点阵样式，避免生成错误皮肤。

## 验证范围

单元测试覆盖显示数据不变、时间单位、真实分词时间、普通整句显示、间奏边界、重叠演唱、网格对齐、砸落、长句末尾、45° 斜线、渐变和设置隔离。

Edge 无头浏览器使用本地模拟歌词与音频特征检查桌面和手机视口、圆点与方格、扫线与高潮、控件、设置持久化、播放列表及滚动歌词切换，并验证暂停及遮挡后画布稳定。模拟检查没有播放真实音频；尚未进行 iOS／Android 真机验证。
