# 跨平台搜索

搜索页提供网易云、QQ 音乐、酷狗、JOOX、Spotify、B 站、Zephyrus 云端及本地等来源筛选。部分来源需要账号或相应服务支持。

## 使用

1. 点击主界面顶栏搜索入口，输入关键词。
2. 选择歌曲、歌单等内容类型。
3. 按需要查看全部结果或指定来源。
4. 核对歌名、歌手和歌曲版本后播放。

各来源的结果可能先后出现。同一首歌的现场版、翻唱、伴奏与录音室版需要分别确认。

## 平台能力差异

各端可用的来源和功能可能不同，请以当前界面的来源选项为准。Spotify 等平台的账号授权与播放还受平台权限限制。

## 登录与权限

在“我的”中添加和切换平台账号，歌曲和音质的可用范围由该账号及平台授权决定。

账号设置分别见 [网易云](/cookie/netease)、[QQ 音乐](/cookie/qq)、[酷狗](/cookie/kugou)。

## 分享链接

在搜索页粘贴网易云、QQ 或酷狗分享文本，识别歌曲后点击卡片播放。

浏览器自动读取剪贴板需要授权，手动粘贴可直接使用。Android 还可以通过系统分享菜单将支持的链接发送到应用。

## 无结果或播放失败

尝试缩短关键词、换来源或重新登录。反馈时提供歌曲平台、ID、设备和错误提示，便于排查。
