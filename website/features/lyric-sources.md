# 歌词源与优先级

Zephyrus Music 支持音乐平台歌词和社区制作的 TTML 歌词。可以调整来源优先级，也可以为当前歌曲临时换源。

## TTML 库

支持自有 Zephyrus TTML 库与 AMLL TTML，优先尝试已配置的自有库。TTML 可包含主唱、背景和声、对唱、翻译及罗马音。

部分歌曲会先显示平台歌词，TTML 加载完成后在下一行切换。

## 请求源排序

打开“播放设置 → 控制 → 数据 → 歌词来源”，选择默认来源或拖动排序。

| 来源    | 歌词类型                         |
| ------- | -------------------------------- |
| 网易云  | LRC、YRC、翻译及罗马音           |
| QQ 音乐 | QRC 或普通歌词，部分请求需要登录 |
| 酷狗    | KRC 或 LRC                       |
| 社区    | 社区匹配歌词                     |
| LRCLIB  | 普通或同步歌词                   |
| TTML 库 | 带有声部等结构的逐字歌词         |

平台歌词默认依次尝试网易云、QQ、酷狗、社区与 LRCLIB。单曲临时换源只在本次使用中有效。

换源后请核对歌手、现场版或录音室版等信息，同名歌曲可能匹配到其他版本。

## 时间与显示

逐字歌词显示词语演唱进度，普通 LRC 按行显示。背景和声与对唱需要 TTML 文件提供对应内容。

翻译、罗马音、时间校准与制作信息可分别设置。智能整理可以合并双语歌词；遇到错误合并，可在歌词末尾反馈，并按歌曲和来源关闭。在歌词来源设置中可以恢复。

## 本地与缓存

本地音乐支持同名 `.lrc`、`.ttml`、`.txt` 文件，增强 LRC 兼容尖括号和方括号逐字标记。

已加载的歌词可缓存在设备上。离线听歌还需要本地音频文件。
