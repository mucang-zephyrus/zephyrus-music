# 图片与视频分享

打开播放设置中的“分享歌曲”，选择图片分享或视频分享。

## 图片分享

用歌曲信息或选中的歌词生成海报，可调整布局、字体、字重、配色、二维码和水印。

布局包括撕纸、沉浸式、演出档案与印章巡演。演出档案突出封面、歌曲信息和大字号歌词；印章巡演带有印章及日期元素。

生成前可在预览中检查长歌名、作者名和多行歌词的排布，完成后保存或分享。

## 视频分享

选择歌曲时间段，将播放器画面导出为视频。可设置：

- 16:9、9:16、3:4、4:3 比例。
- 起止时间。
- 720p 或 1080p 清晰度。
- 水印与深链二维码。

设备支持时优先导出 MP4，否则尝试 WebM。导出需要可用编码器和音频资源，不同 WebView 与浏览器的支持情况可能不同。

词云、点阵暂不支持视频导出，可使用图片分享。

## 保存前检查

确认歌词、画面比例、字体与二维码，导出完成前保持页面打开。分享作品时留意所用字体、封面、歌词及音频的授权范围。
