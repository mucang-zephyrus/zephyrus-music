# AI 歌词分析

AI 可以分析歌词中的意象、叙事与修辞，支持流式展示、Markdown 和纯文本复制。使用前需配置服务商和 API 密钥。

## 配置与使用

1. 在全局设置中找到“歌词 AI 解析”，选择服务商。
2. 填写 API 密钥和模型；自定义服务还需填写接口地址。
3. 打开歌曲，在播放设置中找到“歌词解析”，开始分析。

模型下拉列出常用名称，也可以手动输入。模型可用范围与额度请在服务商控制台确认。详见 [密钥与服务商配置](/guide/free-api-keys)。

## 请求与本地保存

密钥配置和已完成的分析结果保存在当前设备。发起分析时，歌词与歌曲信息会发送给所选服务商，密钥用于鉴权。

AI 歌单、私人 FM 等功能也使用这份配置，输入内容随功能而异。服务商的数据处理方式、额度及费用按其规则执行。

## 故障排查

| 现象               | 检查方向                           |
| ------------------ | ---------------------------------- |
| 提示需要密钥       | 是否已填写并保存                   |
| 401／403           | 密钥、账号权限和接口地址           |
| 模型不存在         | 服务商提供的精确模型 ID            |
| 长时间连接或中断   | 网络、跨域限制、限流和流式接口支持 |
| 分析与当前歌词不符 | 确认歌曲、歌词版本和模型后重新生成 |

分析结果可能有误，涉及歌曲背景等事实时请核对出处。
