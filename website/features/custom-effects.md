# 自定义效果

打开“播放设置 → 控制 → 样式”，选择样式并切换到“自定义设置”。原始设置使用默认外观。

## 按样式保存

各样式分别保存背景、颜色、字体、字重和专属参数，一键还原可恢复当前样式的默认值。

点阵使用像素字形，词云提供整曲排版与镜头设置。其他可调项目见对应样式页面。

## 主要效果

| 样式 | 可调整的效果                                 |
| ---- | -------------------------------------------- |
| 默认 | 封面布局、极光、流体、AMLL 网格与音频响应    |
| 舞台 | 歌词变色、逐字砸下、错落、鼓点闪白及高潮撕裂 |
| 星盘 | 圆盘位置、大小、歌词分块、文字大小与旋转     |
| 词云 | 背景、字号、句间距、竖句比例、聚焦与镜头速度 |
| 点阵 | 圆点／方格、高潮动画、鼓点响应与分词砸落     |
| 烟雾 | 流体、响度响应、暗角、字体拉伸与歌词效果     |
| 错误 | 流体类型、CRT、噪点、抖动、闪烁与边缘光      |

烟雾的重点字与逐字砸下互斥。逐字动作需要带词级时间的歌词。

## 配色

可设置基础歌词色与高潮主题色。支持分部件配色的样式中，主歌词、辅助声部和翻译可以分别跟随主题色或使用自定义颜色。

## 性能与恢复

流体和高帧率背景会增加耗电，掉帧或发热时可以降低质量、强度或帧率。

设置后没有生效时，先确认正在编辑的样式及自定义模式，再关闭、重开面板检查。存储受限或浏览器隐私模式可能影响保存，写入失败时请留意提示。
