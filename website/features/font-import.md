# 字体与字重

播放器可选择系统字体、内置字体或导入字体。海报与状态栏歌词也有各自的字体设置。

## 播放器字体

打开“播放设置 → 控制 → 样式”，选择当前样式并开启自定义设置，在字体项目中选择或导入。

各样式分别保存字体和字重。实际粗细取决于字体提供的字形，点阵主歌词使用 Fusion Pixel Font 像素字形。

## 状态栏歌词

Android 悬浮歌词支持导入 TTF／OTF，文件最大 20 MB。导入后保存在应用中，详见 [状态栏歌词](/features/status-bar-lyrics)。

## 海报

在分享面板中选择字体和字重，生成前检查预览。布局会影响字号与文字排布。

## 导入失败

确认字体文件有效、包含所需字符，并已开启自定义设置。大字体可能加载缓慢或超出存储配额，可以尝试较小的字体文件。

清除应用数据或卸载会影响已保存的字体。分享海报时请留意字体的使用许可。
