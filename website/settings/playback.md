# 播放与歌词设置

全屏播放器设置分为“歌曲”和“控制”两页。歌曲页提供当前歌曲相关操作；控制页包含样式、布局、数据、音频、播放、工具、分享七个模块。

## 样式与布局

在“控制 → 样式”选择默认、舞台、星盘、词云、点阵、烟雾或错误。开启自定义设置后编辑，一键还原可恢复当前样式的默认值。

默认样式可调整封面与歌词区域，星盘可调整圆盘位置，词云可调整排版与镜头。详见 [样式总览](/styles/overview)。

## 数据与歌词

在“控制 → 数据”管理歌词来源、请求顺序和单曲临时换源。翻译、罗马音、时间校准与制作信息也可分别调整。

逐字进度需要逐字歌词，背景和声与对唱需要 TTML。智能合并有误时，可按歌曲和来源关闭整理。

## 音频与播放

可调整音量、播放速度、音质、过渡与定时关闭。可用音质受歌曲来源和账号权限限制。

iOS Web 可开启防打断模式，启用后会关闭媒体通知和锁屏控制，系统静音也可能影响出声。

## 工具与分享

歌词分析需要服务商和 API 密钥，详见 [AI 歌词分析](/features/ai-lyric-analysis)。

图片分享可生成海报；视频分享可选择时间段、比例和清晰度。词云、点阵暂不支持视频导出，详见 [图片与视频分享](/features/posters)。

## 状态栏歌词

Android 可以在其他应用上方显示歌词。授权悬浮窗权限后，可调整位置、字体及颜色。详见 [状态栏歌词](/features/status-bar-lyrics)。
