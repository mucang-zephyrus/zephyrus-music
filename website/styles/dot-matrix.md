# 点阵样式

圆点或方格组成歌词字形，背景随音乐出现渐变、扫线和高潮动画。

## 歌词显示

使用 Fusion Pixel Font 像素字体，长句自动换行。歌曲播放期间网格大小保持稳定。

普通 LRC 整句显示，逐字歌词按词语出现。分词砸落让文字从上方向下落入网格，可在自定义设置中关闭。

支持翻译、罗马音、时间校准与歌词来源切换。

## 音乐响应

前奏和间奏时，网格可随节拍点亮、渐变；响度较高时，45° 斜线扫过屏幕。高潮动画提供同心波纹、棋盘呼吸与放射推进，可自动轮换或固定一种。

节拍效果需要音频分析支持，高潮动画需要歌曲的高潮标注。

## 自定义与性能

可调整圆点／方格、高潮效果、鼓点响应、分词砸落、间距、半径、字形高度和效果强度。

暂停后画面逐渐静止，减少动态效果模式会关闭背景运动和砸落。

支持图片海报，暂不支持视频导出。
