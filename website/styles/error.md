# 错误样式

高速流体或太阳耀斑背景，配合 CRT 扫描线、噪点、歌词溶解和高潮故障效果。

::: warning 光敏提示
此样式包含强烈闪光与快速变化画面。对闪光敏感时请选择其他样式。
:::

## 自定义

在“播放设置 → 控制 → 样式”选择错误，开启自定义设置。可调整背景类型、流体力度、噪点、歌词抖动、高潮闪烁、边缘光及装饰符号。

歌词支持翻译、罗马音与时间校准，高潮效果使用歌曲的高潮标注。

## 性能

流体背景需要 WebGL，设备发热或卡顿时可降低背景强度。闪烁和抖动也可分别调整。

视频导出的设置与要求见 [图片与视频分享](/features/posters)。
