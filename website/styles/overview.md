# 播放器样式总览

Zephyrus Player 提供七种播放器样式：

| 样式                       | 主要特点                           | 说明                     |
| -------------------------- | ---------------------------------- | ------------------------ |
| [默认](/styles/default)    | 大封面、滚动歌词与动态背景         | 适合日常播放             |
| [舞台](/styles/stage)      | 巨幅歌词、鼓点闪白、错落与逐字砸下 | 突出演唱与高潮           |
| [星盘](/styles/star-chart) | 圆盘旋转与分块歌词                 | 可调整圆盘位置及文字布局 |
| [词云](/styles/word-cloud) | 整曲歌词画布与跟随镜头             | 已替换旧狂热入口         |
| [点阵](/styles/dot-matrix) | 网格组成歌词字形                   | 支持圆点、方格与节拍动画 |
| [烟雾](/styles/smoke)      | 主题色流体、响度响应与拉伸歌词     | 动态背景需要 WebGL       |
| [错误](/styles/error)      | 流体、CRT 噪点与故障闪烁           | 启用前阅读光敏提示       |

## 选择与自定义

打开全屏播放器设置，在“控制 → 样式”选择样式。原始设置使用默认外观，切换到自定义设置后可以调整背景、颜色、字体、字重和专属参数。

各样式分别保存配置，一键还原只影响当前样式。点阵使用像素字形，词云提供整曲排版和镜头设置。

## 歌词与音频数据

逐字进度需要 TTML、YRC、QRC、KRC 或增强 LRC 等逐字歌词，普通 LRC 按行显示。TTML 还可显示背景和声与对唱。

高潮效果使用歌曲的高潮标注，鼓点和响度响应需要音频分析支持。Web 在线音频的分析受跨域限制。

## 性能与分享

流体和高帧率背景会增加耗电，发热或卡顿时可以降低质量、减少运动或关闭背景。

词云、点阵可生成图片海报，暂不支持视频导出。其他样式的视频导出需要可用编码器。详见 [图片与视频分享](/features/posters)。

旧诡谲、陈旧、雨夜已移除，狂热选择会迁移为词云。Android 安装包与 Web 分别更新，缺少新样式时可查看[安装与更新](/guide/installation)。
