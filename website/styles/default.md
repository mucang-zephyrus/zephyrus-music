# 默认样式

以封面、歌曲信息和滚动歌词为主，适合日常播放，支持横竖屏。

## 封面与布局

在“播放设置 → 控制”的样式、布局模块调整封面大小、对齐、圆角、阴影，以及歌曲信息和歌词区域。唱片封面可显示圆形图片与黑胶外圈。

从封面页进入歌词页时，歌词区域会扩展到屏幕；点击歌词页顶部的小封面可返回。

## 背景

可选极光、流体或 AMLL 网格渐变，也可以关闭动态背景。网格可调整帧率、渲染倍率、静态模式和音频响应。

Web 在线歌曲的音频响应受跨域限制。

## 歌词

支持翻译、罗马音、时间校准、点击跳转和手动滚动。字体与颜色按当前样式保存。

详见 [歌词来源](/features/lyric-sources) 与 [自定义效果](/features/custom-effects)。
